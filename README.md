# Trabalho Final

A nota do curso é formada pela soma da Prova Semestral 1 (peso 30) + Prova Semestral 2  peso 30  e a entrega de um trabalho final (peso 40).

Sobre o trabalho final

O trabalho final pode ser feito individualmente, em duplas ou trios. Nele, deverá ser entregue um projeto simples feito em Python, utilizando os conceitos vistos em aula.

Exemplos de projeto incluem calculadoras, ferramentas de conversão de medidas, controle de estoque, organizadores de arquivos, gráficos sobre dados retirados da internet, jogo simples, entre outros.

### Observações

- A data final para entrega do trabalho é dia 26/11/2025
- O trabalho será avaliado em sala, não havendo necessidade de entrega
- O professor estará em sala dia 3/12/2025 para feedback dos trabalhos
- Pesquisa é fundamental para este projeto!

### Considere (não obrigatório):

- Criar uma interface gráfica simples
- Gerar um arquivo executável (.exe) para rodar o programa final
- Subir seu projeto no github
- Utilizar bibliotecas como Matplotlib, Tkinter ou Numpy para seu projeto
